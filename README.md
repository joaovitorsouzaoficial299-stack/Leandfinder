# LeadFinder
Projeto de um arquivo só: `index.html`. Sem build, sem pastas.

## Publicar pelo iPhone
1. No GitHub (Safari): New repository > Add file > Upload files > escolha `index.html` e `README.md` > Commit.
2. Na Vercel: Add New > Project > importe o repositório > Framework Preset: Other > Deploy.

## Busca real
Funciona direto no navegador via OpenStreetMap (grátis). Para avaliações, ponha uma chave do Google Places em Configurações.
